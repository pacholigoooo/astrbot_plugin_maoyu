# 毛玉小院 · AstrBot / Koishi 插件

一只软乎乎的毛玉，六套东方主题装饰。轻量、离线、不调用大模型。

## 安装

1. 使用 AstrBot 4.9.2 或更新版本，先备份已有机器人数据。
2. 在 AstrBot WebUI → 插件管理中使用 ZIP 安装，选择 `astrbot_plugin_maoyu_v1.3.0.zip`。
3. 如果你的版本没有 ZIP 安装入口，解压后把 **astrbot_plugin_maoyu 整个文件夹** 放入 AstrBot 的 `data/plugins/`，然后重启或重载插件。注意不要变成两层同名目录；`main.py` 应位于 `data/plugins/astrbot_plugin_maoyu/main.py`。
4. 依赖仅 Pillow（requirements.txt）。如提示缺失，在 **AstrBot 实际运行的 Python 环境/容器内**运行 `python -m pip install -r data/plugins/astrbot_plugin_maoyu/requirements.txt`。
5. 向机器人发送 `/毛玉 帮助`，再发送 `/毛玉 领养 糯米`。

不需要 API Key、模型、浏览器、外部图片服务或额外字体下载。无需改动其他宠物插件。

> `/` 是示例唤醒前缀；如果你改过 AstrBot 的前缀，请使用自己的前缀，部分群需要先 @机器人。所有玩法统一使用“毛玉”前缀，避免和其他插件的“签到/散步”等命令冲突。

## 养成规则

- 初始40团子币、85饱食、85心情、90精力；首套装饰免费。
- 装饰售价80/100/120团子币，只有外观区别，没有战力加成。
- 散步固定增加20经验、最多10心情，获得15～24团子币和一次纪念品发现；重复纪念品不重复计数。
- 经验达到50/200/450/800时升级到2/3/4/5级，后续按同一二次曲线增长。等级是成长记录，不增加数值压力。
- 清醒每小时减少1.5饱食、0.8心情，恢复2精力；睡觉每小时减少0.4饱食、恢复24精力。数值上限100。
- 每次离线结算最多计入24小时清醒衰减；饱食下限15，心情下限20。不会死亡，也不会失去装饰。状态在收到指令时计算；查询只返回快照，不写回时间游标，成功写操作才保存。无需定时任务。
- 最近五次散步保留为小院手记，收藏永久保留。
- 成就：初次出门10币、散步10次30币、收集6种30币、拥有3套主题装饰30币、升到5级40币、收齐12种60币。达成后的写操作自动发奖，每项仅一次。旧版已达成的里程碑在升级时识别，但不补发奖励。
- 文字反馈显示实际变化，不把达到上限后未获得的数值算进去。
- 对平台提供的消息ID进行7天写操作去重；平台没有消息ID时依靠冷却和交易校验，无法保证识别所有重投。
- 所有东方事件为本插件的同人创作，不作为原作设定资料。

## 配置

插件设置中可改：

- `send_images`：默认 true。关闭只发文字，便于图片不兼容的平台使用。
- `cooldown_scale`：默认1，范围0.1～10，改变喂食、摸摸、玩耍、散步冷却。不会改变睡觉时长或签到日界线。
- `auto_backup`：默认true。每个UTC日首次成功操作后备份一次，保留最近7份。
- `utc_offset`：默认8，范围-12～14。仅影响签到换日，采用固定UTC偏移，不自动处理夏令时。

更改后重载插件。固定每用户2秒命令节流。数据库使用独立单线程队列，总容量32（含执行中）；超出时明确提示尚未执行。渲染使用独立双线程队列，总容量4（含执行中）；超出时只发文字，已经提交的操作不丢失。请求取消不会提前释放正在运行的工作容量。插件卸载时停止接收新任务，并等待已接纳任务完成。

## 存档、隔离与备份

位置：AstrBot 数据目录下 `plugin_data/astrbot_plugin_maoyu/maoyu.sqlite3`。
用框架数据目录 API 定位，不依赖启动目录，也不把数据库放进插件代码文件夹。

按“平台实例＋群ID＋用户ID”隔离；同一个人在不同群分别养不同毛玉，私聊也独立。不会显示或上传用户ID，不读取群聊历史。

- 更新插件：保留 `data/plugin_data/astrbot_plugin_maoyu/`，仅替换插件代码目录。
- 备份：先停止 AstrBot，再复制整个数据文件夹（包括可能存在的 `-wal`、`-shm` 文件）；恢复也在停止状态进行。
- 不要在运行时只复制 `.sqlite3` 主文件，WAL可能尚未合并。
- 自动生成的状态卡在 `cards/` 中，每小时最多触发一次清理：删除超过24小时的文件，再将10分钟前的旧缓存尽量裁减到512张；保留最近10分钟文件以免平台尚未上传完。没有新图片请求时不进行定时清理。缓存文件名随机，不含用户ID。
- 自动备份在 `backups/maoyu-YYYY-MM-DD.sqlite3`；使用SQLite在线备份API，不直接复制活动中的WAL文件。备份失败会记录日志，不回滚已经成功的游戏操作。
- 1.0升级前会单独保存 `maoyu.pre-v1.1.sqlite3`，默认不自动删除。回退1.0应在停机后用这份旧格式备份恢复，不能直接拿1.1数据库给1.0读取。
- 保存出错时不会偷偷重建数据库；请保留原文件，按日志排查。
- 数据库标记比当前插件更新时会拒绝启动，避免旧版覆盖新版数据。

## 图片与平台兼容

毛玉本体和六套外观全部由图像生成工具生成；最新版本已经去掉身体上的围巾、领结、系带和铃铛。保留头饰、翅膀与独立小道具。
运行时只读取图片、缩放排版和绘制文字/状态条，不用代码重新画角色。PNG素材保留透明通道，使用最近邻缩放。

本版表情固定为愉快表情；饥饿/睡眠由文字状态标明。GIF仅为整体轻晃，不冒充已经做好的闭眼睡觉或喂食动画。

通过 AstrBot 的 `event.image_result` 发送本地图片。部分适配器或官方平台可能要求可访问的图片URL，或不支持GIF；这种情况下先关掉 `send_images` 文字游玩。**1.3.0通过104项Python测试、6组Koishi测试，以及AstrBot 4.9.2/4.29.1各20条真实框架指令检查**，但尚未连接实际QQ账号、发送到真实群；不能保证所有适配器都能直接发图。

## 像素界面

- 状态图为800×1040，衣柜为800×1320；聊天缩略图可点开查看原图。
- 低饱食、低精力、低心情和睡眠分别显示状态；休息时显示预计自然醒分钟数。
- 衣柜明确标注穿戴中、已拥有、首套免费任选及余额不足差额。
- 手记最多展示两行，溢出用省略号表示，完整内容使用 `/毛玉 日记`。
- 图片不是可点击按钮，请在聊天框输入指令。
- 1.1.0/1.2.x升级到1.3.0不改变数据库结构；仍应停机备份并保留plugin_data。
